# Contributing

Thanks for helping keep these roadmaps accurate.

## Good contributions
- An exam code changed or a certification was retired (link the official announcement)
- A missing certification that is widely requested in job posts
- A clearer description of what a certification is for

## Not accepted
- Exam dumps or real exam questions (they break certification NDAs)
- Affiliate or referral links
- Paid courses presented as required

## How
1. Open an issue describing the change, or
2. Fork, edit the relevant file in `roadmaps/`, and open a pull request with a source link.
